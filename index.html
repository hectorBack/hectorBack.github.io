Sobre Mí

Soy Ingeniero en Sistemas Computacionales y Desarrollador Full Stack apasionado por la creación de aplicaciones web modernas, seguras y escalables. Tengo experiencia desarrollando soluciones completas utilizando Java, Spring Boot, C#, ASP.NET Core, React, Next.js y bases de datos relacionales.

He desarrollado sistemas de gestión escolar, plataformas administrativas y aplicaciones para restaurantes, participando en todo el ciclo de desarrollo: diseño de bases de datos, desarrollo de APIs REST, implementación de seguridad con JWT y creación de interfaces web responsivas.
